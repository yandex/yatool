# Ключ AC для UID ya

Библиотека задаёт существующее преобразование `uid_to_uri(uid)` из строкового UID ya
в 64-символьный ключ `/ac/`. Её используют клиент BazelStore и независимая проверка
прогрева. HTTP, runner и Tasklet SDK в зависимостях отсутствуют.

Короткий UID кодируется в UTF-8 и hex, дополняется нулями и завершается версией `1`.
Если остаётся меньше двух символов, применяется SHA-256 от hex-строки;
два последних символа заменяются на `11`. Правило сохранено без изменений:
новые и старые клиенты обращаются к тем же ключам.

Это ключ метаданных ya, а не SHA-256 от стандартного protobuf Action.
Ключ CAS по-прежнему равен SHA-256 содержимого файла. Изменение алгоритма AC
требует отдельной версии протокола; длины и известные значения проверяют тесты.
